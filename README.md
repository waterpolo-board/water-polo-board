# לוח טקטי כדורמים

לוח אינטראקטיבי לתכנון מהלכים בכדורמים — בריכה 30×20 מ' עם קווי 2 מ' (אדום), 5 מ' (צהוב) ואמצע.

## הרצה
פשוט לפתוח את `index.html` בדפדפן, או להריץ שרת מקומי: `node dev-server.js` ולגלוש ל-http://localhost:5173

## מה יש כרגע
- 2 קבוצות × 7 שחקנים (שוער בכובע אדום) + כדור — גרירה חופשית
- ציור חיצי תנועה (לבן) וקווי מסירה (צהוב מקווקו)
- ביטול ציור אחרון, ניקוי ציורים, איפוס מיקומים

## מבנה
- `index.html` — מבנה הדף וסרגל הכלים
- `style.css` — עיצוב
- `app.js` — ציור הבריכה, שחקנים, גרירה וציור
