# לוח כדורמים

לוח טקטי אינטראקטיבי לכדורמים, לטאבלט. בריכה 25×20 מ', מצבי 6 על 6 ו-6 על 5, מהלכים מונפשים.
**האפליקציה:** https://waterpolo-board.github.io/water-polo-board/

האיפיון המלא ב-[SPEC.md](SPEC.md), התוכנית ב-[tasks/plan.md](tasks/plan.md). כל push ל-`main` נבדק, נבנה ומתפרסם אוטומטית.

## הרצה
```
npm install
npm run dev        # http://localhost:5173
npm test           # בדיקות
npm run build      # בנייה ל-dist/
```

## איך משתמשים
- **מצב:** בריכה מלאה / 6 על 6 / 6 על 5 (למעלה).
- **הזזה:** גוררים כובע או כדור. **חץ תנועה / מסירה:** מציירים על המים.
- **מהלך:** "+ שלב" משכפל את השלב הנוכחי, מזיזים, ושוב. "הפעל מהלך" מנגן הכול.
- **בטל / חזור** לכל פעולה. הכול נשמר אוטומטית.
- **ספרייה:** "שמור" שומר את המהלך עם שם ותגיות. "ספרייה" פותח את הרשימה; ▶ ליד מהלך פותח ומנגן אותו מיד. הכול נשמר על המכשיר. "ייצוא גיבוי" שומר קובץ להעברה לטאבלט אחר.
